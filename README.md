# Storage Estimator - Main and Feature Version

## Project Purpose
This project is a simple Python script created for ICT lab to demonstrate fundamental version control workflows using Git and GitHub. The program takes a storage value in Gigabytes (GB) from the user and converts it to Megabytes (MB).
Note: 1 GB is calculated as 1024 MB.

## How to Run the Program
To run this script, open your terminal or command prompt, navigate to the folder containing the file, and execute the following command:

```bash
python storage_estimator.py
```

## Example Input and Output
**Example Input:**
```text
Enter storage in GB: 2.5
```

**Example Output:**
```text
Storage in MB: 2560.0
```
